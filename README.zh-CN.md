把对话、个人背景和持续跟进的目标放在一起。从一个问题开始，留下重要线索，下次回来时继续推进。你选择兼容的模型端点和 API Key；Echo 在你的 Mac 上运行，并在本机保存记录。

## 陪你推进需要持续投入的事

| 当你想…… | Echo 可以帮你…… |
|---|---|
| **想清一个问题** | 讨论思路、润色提问、查找来源，回到已有对话继续交流。所选模型支持时，还可理解图片或生成图片。 |
| **为一个目标做准备** | 明确完成标准和下一步。开启后台研究后，基于公开来源、附加文档和选定文件夹准备资料，跟进相关日期或来源变化。 |
| **处理一个项目** | 连接本地工作区读取文件，按需开启编辑或命令执行。工具活动与执行记录可供查看。 |

## 让上下文持续有用

**记忆由你管理。** 查看、保护、恢复或删除记住的事实，选择记忆档位，调整交流偏好。久未使用的信息可以淡出，需要留下什么由你决定。

**跟进节奏由你选择。** 后台研究默认关闭，在 **主动服务** 中开启后，可为每个目标选择来源。研究和通知分别控制，呈现遵循静默时段与频率限制。你可以查看成果、纠正内容、暂停目标或标记完成。

**屏幕上下文按需开启。** 屏幕感知与伴随模式默认关闭。开启并授予 macOS 屏幕录制权限后，Echo 可结合近期屏幕内容提供简短建议；选择深度记忆档也会开启屏幕感知。随时可在状态栏暂停采集。

## 清楚知道自己分享了什么

| 控制项 | 实际行为 |
|---|---|
| **模型连接** | 对话，以及回答时使用的记忆、文档片段、图片或工具结果，会发送到你配置的模型端点。能力、数据处理方式与费用取决于所选提供方。 |
| **本机记录** | 对话、记忆、目标和执行记录保存在 Mac 上，提供导出与删除入口。本机存储不代表模型请求离线，也不能撤回已经发给提供方的数据。 |
| **研究范围** | 后台研究仅使用只读工具和你允许的来源，搜索词会发送给所配置的搜索提供方。它不能运行 Shell、调用 MCP、编辑文件或联系他人。 |
| **工作区权限** | 工作区工具默认关闭，读取、编辑与 Shell 分别控制。Shell 和 MCP 调用需要逐次确认；Shell 使用本机账号权限运行，不是操作系统沙箱。 |

屏幕采集默认在本机进行 OCR，提取的文字可能发送给模型；图片模式可发送截图。本机工作区执行与确认仅在宿主 Mac 上开放。

Echo 也可向局域网开放对话，默认不要求口令。在共享网络上使用前，请开启口令保护或限制为仅本机访问。完整说明见[权限与数据指南](docs/permissions.md)。

## 开始使用

1. **下载 macOS 版本。** 在 [v0.1.0-alpha.6](https://github.com/Lazarus-coder/echo-assistant/releases/tag/v0.1.0-alpha.6) 选择 macOS 安装包。当前安装器面向 macOS 13+，支持 Apple Silicon 与 Intel，需要 Node.js 22.13 或更高版本。
2. **连接你的模型。** 运行 **Install Echo.command**，在引导中填写兼容端点、API Key 和模型。安装器会添加状态栏应用及登录后启动的服务。
3. **选择需要的能力。** 开始一段对话，选择记忆档位，再按需开启后台研究、屏幕上下文或工作区访问。

模型与搜索调用可能产生所选提供方的费用。[开始使用指南](docs/getting-started.md#中文)说明安装、访问控制与卸载；源码安装见[开发指南](docs/development.md)。

## 仍在成长，也说明边界

Echo 目前处于 **alpha**。界面与数据格式可能调整，升级前请备份。研究结果需要你复核；只有 Mac 唤醒且 Echo 运行时才会执行检查。目前不会自动读取浏览器、邮箱或日历；没有可提取文字的扫描 PDF 会明确报告不可读。

本仓库介绍当前源码能力，已发布安装包可能落后于源码；请以下载版本的发布说明为准。

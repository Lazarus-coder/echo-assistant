<a id="定位"></a>
## 定位

大多数助手是"你问我答"。Echo 押的是相反的一注：一个 **BYOK 的私人 agent，并具备主动能动性（proactive agency）**——常驻在你机器上，维护一份"允许被遗忘"的记忆，在有值得说的话时主动找你。

| | |
|---|---|
| **BYOK，不是"我们的云"** | 任意 OpenAI 兼容端点（OpenAI · 阿里云百炼 · DeepSeek · Moonshot · OpenRouter · Ollama · 你自己的网关）。密钥写在 `data/echo.env`（600）——不进 config、不进 git、不进日志。换供应商不用改程序。 |
| **能动性，不是自动补全** | 你睡觉时它在巩固记忆、**有意识地遗忘**、为你采纳的目标准备成果，并决定何时呈现——从明确结果反馈中学习。 |
| **本地优先，不是托管服务** | 使用 Node 标准文件/进程 API 与官方 MCP SDK，无向量库、无 Echo 账号。记忆与执行记录是 `data/` 下的明文文件：可读、可备份、可删除。 |
| **一人一机** | 设计上就是单用户：一个状态栏图标、一个对话窗口、一个给手机的局域网地址。没有多租户那一套。 |

它**不是**：套了好看皮肤的聊天壳、云端记忆服务、多 agent 框架。想要一个带团队功能的托管助手，Echo 是故意不合适的工具。

<a id="byok"></a>
## BYOK —— 什么都可以自带

### 模型

指向任意 OpenAI 兼容端点即可；首次引导会给出常用预设，然后**测试连通并拉取你账号下的模型列表**（`GET /models`）。你选默认模型、后台杂活模型（标题、记忆抽取、Dream），以及可选的出图模型（留空则该工具直接不存在）。

能力跟着你的端点走，不靠承诺：

| 能力 | 需要 | Echo 的表现 |
|---|---|---|
| 对话 / 流式 / 工具调用 | 基础 API | 核心循环 |
| 视觉理解（粘贴/拖拽/上传） | 支持视觉的模型 | 上传前客户端压边 |
| 出图 | 出图模型 id | `image_gen` 工具 + 界面"画图"；结果**落盘本地**（远端链接会过期） |
| 托管联网搜索 | 实现 Responses API 的端点 | `gateway` 搜索提供方，无需额外订阅 |
| 语音 / 视频 | 暴露 `/audio`、视频接口的端点 | 有就接上，没有就当作已知缺失 |

端点若不具备某能力，对应工具会**直接不出现**，而不是调用时才报错；主模型不可用时走**降级链**，而不是把你的这轮对话丢掉。

### 搜索（可插拔，用你的 Key 或干脆不用）

搜索是一条**你自己配的链**，按顺序尝试；前面的失败（限流、缺 Key）自动交给下一个。密钥从 `data/echo.env` 的环境变量读取。

| 提供方 | 需要 | 说明 |
|---|---|---|
| `none` | — | 明确不联网 |
| `scrape` | — | 零配置抓取；最快，可能被第三方限流（有熔断冷却） |
| `gateway` | — | 你端点的托管搜索（Responses `web_search`，3–8s，带 sources） |
| `tavily` · `brave` · `bocha` | API Key | 面向 LLM / 独立索引 / 中文结果好 |
| `searxng` | 实例地址 | 你自己的聚合实例 |
| `custom` | — | 任何返回 `{results:[{title,url,snippet}]}` 的 HTTP 接口 |

<a id="对话窗口"></a>
## 对话窗口

流式回答 + 思考折叠 · 工具步骤与来源可展开 · 编辑重发 · 重新生成 · 每个会话单独选模型 · 图片粘贴/拖拽/上传 · 接你的出图模型的一键画图 · 会话置顶/导出 · token 用量 · 深浅色 · 手机尺寸适配。

**输入润色（⌘⇧P）**：把你手里那半句话（"那个部署脚本老是超时，帮我看看"）打进去，点「润色」。它会跑一遍小型的 CoT：读对话尾部、读与草稿有实际词面重叠的记忆、读你此刻在做什么，然后猜意图、列缺口、把请求补到可执行的粒度。你能看到它理解的意图、缺口和它替你做的假设（都可编辑），选模式——**细化 / 保守 / 精简**，然后替换输入框或直接发送。你的原文永远不会被静默替换；它也不会编对象：草稿太模糊（"帮我看看 "）时，它会**反过来问你**要看什么，而不是拿记忆里的东西替你决定。万一记忆里独有的名字漏进了正文，还有一道确定性护栏会去掉记忆重写一次。

<a id="工作区执行"></a>
## 工作区执行

在运行 Echo 的 Mac 上打开 **工作区**，选择已有的项目目录，再分别开启读取、编辑文件、Shell 权限。工作区工具默认关闭。之后直接在对话里描述任务，例如：“检查这个项目，修复失败的检查，再验证修改。”

- **读取与编辑真实文件。** 目录和文本支持分页；编辑必须提供最近读取的文件哈希，拒绝有歧义的替换，并保存修改前后快照。文件工具拦截路径越界、符号链接和 Echo 私有数据路径。
- **查看命令再执行。** 每次 Shell 调用都会展示完整命令、工作目录与参数，等你批准。stdout/stderr 在对话中流式显示并保存为可下载文件；模型可用 `read_output` 分页读取日志。退出码、失败、超时和截断都有明确记录。
- **复用标准工具生态。** 现有 OpenAI 兼容工具循环通过[官方 MCP SDK](https://ts.sdk.modelcontextprotocol.io/client)接入 stdio 与 Streamable HTTP 服务。MCP 调用同样逐次确认并保存记录，服务的能力描述不会自动授予权限。在 `mcpServers` 配置服务后，从设置里重新加载 MCP。子进程只继承少量环境变量；服务需要的凭据须通过对应的 `env` 显式传入。
- **每次运行有边界、有记录。** 默认最多 12 轮工具调用、32 次调用，Shell 超时 60 秒，stdout/stderr 合计上限 2 MiB。用完预算后，模型根据实际结果总结。停止会取消模型与工具工作，并终止本机命令进程组；更改权限会取消当前运行。服务重启后标记中断，不自动重放操作。

在 **工作区 → 本对话的执行记录** 查看完整输入、结果、批准记录、文件修改及输出下载。记录保存在 `data/runs/`，直到“全部忘掉”清除；对话 JSON 导出不包含这些独立输出文件，需要时另行备份此目录。快照用于检查和手动恢复，不代表支持一键撤销。

Shell 是**受信任的本机执行，不是操作系统沙箱**：工作目录不能阻止命令访问其他文件或网络。只批准你信任的命令和 MCP 服务。工作区配置、执行、确认与输出下载仅供本机访问；局域网对话没有本机执行工具。用于对话的文件内容和工具结果会发送给你配置的模型端点。远程 MCP 服务需配合取消，已经完成的操作不能靠停止撤销。

后台目标准备沿用原有只读范围；开启工作区不会给无人值守的目标授予 Shell 或文件写入权限。

<a id="主动能动性"></a>
## 主动能动性

Echo 可以持续记住你确认的目标，准备具体成果，并在合适的时候呈现。打开 **主动服务 → 持续推进的目标**，使用这五个环节：

1. **持久目标**：新建目标，或把自己的消息、Dream 建议采纳为目标。填写完成标准、下一步、阻碍与可选截止日期；支持暂停、恢复、附完成依据结项和取消。Dream 建议在采纳前只是候选，生成草稿也不等于目标已经完成。
2. **限定范围的准备**：每个目标使用其描述，可单独授权相关记忆与最多三个公开网页。确认、修改或恢复进行中的目标时，自动排队准备本地草稿。每次最多一次模型调用（1,800 输出 token、60 秒）；滚动 24 小时内每个目标最多两次、全部目标最多五次。网页读取有大小限制且不跟随重定向。暂停或修改目标后，进行中的旧结果会被丢弃。成果保存来源时间、摘录、假设与引用检查；检查只确认引用对应和结构，不能证明事实正确。准备使用已配置的模型服务，不向外部应用写入内容。
3. **明确结果反馈**：可以标记采用、帮助完成、无关、内容不对或时机不对。修改反馈会替换旧票；采用后完成只算一次有用干预。时机不对会暂停打扰 30 分钟，不降低有用程度估计。沉默和无关聊天始终是未知。
4. **共享注意力预算**：主动消息与伴随气泡共享每日预算和最小间隔，同时保留各自的渠道上限。静默时段、近期会议或专注状态、最近聊天都会推迟呈现。关闭主动呈现后，目标准备仍可继续；成果可随时在面板查看，过期消息不再主动投递，相同证据不重复打扰。屏幕上下文仅在开启且新鲜时采用，没有聊天不等于设备空闲。
5. **条件触发的跟进**：选择手动、截止临近或授权来源变化。截止日期在两天内触发一次；网页最多每小时检查一次，比较可读内容。读取失败会显示原因，不会被当成变化。准备成果附有证据与观察时间。

目标、准备成果和明确反馈保存在本地，并包含在 JSON 备份中。「全部忘掉」也会清空这些内容。设置提供共享注意力预算；目标面板集中呈现权限和生命周期操作。

普通主动建议仍由 Thompson 采样策略选择类型、结合证据提出候选，再经过共享注意力检查。效用后验只从明确反馈更新。离线 bandit 回放是合成算法测试，不代表真实生产力提升；诊断中可查看实际完成数与明确反馈数。

Dream 继续整理记忆、提出跟进候选，但不会默默把候选变成已承诺目标。

## 伴随模式（显式开启）

主动能动性管的是**时机**，伴随模式管的是**在场**。打开之后，Echo 的看屏幕频率从分钟级提到秒级，并在屏幕角落偶尔浮一张**气泡**：不是通知、不是抢焦点的窗口，而是一张小卡片，你不理它，它自己淡走；鼠标停在上面，它就不走。点一下，弹出一个**小对话窗**，专注在那个话题上，并留下一段独立可继续的会话。

它为之设计的场景（各有各的口吻）：

| 你在…… | 它做什么 |
|---|---|
| **跟人聊天**（微信 / Slack / 邮件） | 读那段对话，判断关系与语气，给一句可直接复制的话 |
| **看片看视频** | 像朋友一样一起看——一句感受、一个背景掌故、一句吐槽；不讲课、不提问 |
| **办公**（文档 / 表格） | 一条具体建议：下一步、容易漏的细节、该复核的数字 |
| **写代码** | 只在真能帮上忙时开口：一个 API 细节、一个边界条件、一个更省事的写法 |

不让它变成骚扰的几条纪律：

- **先做变化检测**：屏幕和上一帧差不多就**完全不调模型**——这是"每 20 秒看一眼"能负担得起的原因，也是它不重复念叨的原因。
- **预算、间隔、退避**：每小时气泡有上限、气泡之间有最小间隔；连续被忽略三次就自动安静一段时间（并写进日志）。
- **绝不抢焦点、绝不阻塞**：气泡会自己过期，悬停即暂停计时；状态栏有"暂停 30 分钟"一键。
- **隐私默认与屏幕感知一致**：本地 OCR、只发文字、截图分析完即删、屏蔽名单照常生效，而且**默认关闭**。

气泡自带"为什么"：卡片只有一句话，点开后那段会话的第一条消息会说清它凭什么觉得值得开口。点开与忽略都会进自报告（`./bin/echo diag`），你能看出这份"陪伴"到底受不受用。

<a id="记忆与遗忘"></a>
## 记忆与遗忘

| 层 | 存什么 | 生命周期 | 用途 |
|---|---|---|---|
| **L0 工作记忆** | 最近 ~90 分钟的屏幕活动摘要 | 自动过期、容量上限 | 知道"你此刻在做什么" |
| **L1 即时事实** | 从对话与屏幕抽取的稳定事实 | 强度衰减，久不用淡出 | 检索召回、L2 的原料 |
| **L2 核心记忆** | `data/memory/MEMORY.md` | 每次 Dream 重写 | 每轮注入，可手改 |
| **L3 归档与图谱** | Dream 快照、遗忘日志、实体图 | 保留可回溯 | 审计、实体召回 |

强度 = 重要度 × 使用增益 × 指数衰减。被检索命中会强化；久不用的事实**淡出**（保留、可复活，不是删除）；超容量时按强度从最弱淘汰；**每一次淡出与遗忘都写进 `memory/forgetting.md` 并附理由**。你可以保护、复活、明确忘掉任何一条。记忆档位（`off · light · standard · deep`）决定这套机制要跑多少。

<a id="安装"></a>
## 安装

**macOS 安装包（推荐，通用二进制：Apple Silicon + Intel）**：到 [Releases](https://github.com/Lazarus-coder/echo-assistant/releases) 下载 `Echo-0.1.0-alpha.4-macos.dmg`，打开后双击 **Install Echo.command**。它把 `Echo.app` 与服务装到 `~/Library/Application Support/Echo`、注册 launchd 常驻、并询问模型端点与 Key（可跳过，网页里有向导）。卸载双击同一目录里的 `Uninstall Echo.command`。

**从源码装**（macOS，Node ≥ 20）：

```bash
git clone https://github.com/Lazarus-coder/echo-assistant.git && cd echo-assistant
./install.sh          # 锁定版本的 npm 依赖 → 凭据 → launchd 常驻 → 编译状态栏
./bin/echo status     # 进程 / 健康 / 局域网地址 / 记忆与主动服务概览
./bin/echo open       # 打开对话窗口
```

| 命令 | 作用 |
|---|---|
| `./bin/echo up / down / restart` | 启动 / 停止 / 重启 |
| `./bin/echo logs` | 跟踪日志 |
| `./bin/echo dream` | 立刻巩固记忆 + 执行遗忘 |
| `./bin/echo say` | 立刻判断一次"要不要主动说句话" |
| `./bin/echo diag` | 自报告：延迟、失败、工具成功率、**明确反馈与目标完成数**、存储 |
| `./bin/echo forget` | 看它忘了什么、为什么忘 |
| `./bin/echo auth on\|off` | 开关口令验证（默认关） |
| `./bin/echo selftest [--live]` | 冻结评估器（隔离沙箱；`--live` 会真调模型） |

手机访问：同一 WiFi 下打开 `http://<Mac 的局域网 IP>:8787`，Safari"添加到主屏幕"即可。公共网络下建议 `./bin/echo auth on`。

开发时先运行 `npm ci --omit=dev --ignore-scripts`，再运行 `npm start`。源码安装需要 Node 20+ 和 npm。`npm run test:harness` 使用临时数据与本地模拟服务检查文件、Shell、MCP、确认、持久化、API 和界面；`npm run test:regressions` 同时覆盖既有功能。

## 权限与常驻

完整说明：[docs/permissions.md](docs/permissions.md)。要点：**默认全部关**（不要口令、不采集屏幕、不发通知）；安装器注册两个 launchd 任务（`com.echo.chat` / `com.echo.menubar`）；屏幕感知（主动决策的输入之一）需要一次系统授权，入口在状态栏图标菜单里。

## 数据与磁盘

```
data/
  echo.env              密钥（600）——不进 config、不进 git
  conversations/*.json  消息、工具轨迹、用量、滚动摘要
  runs/*/               run.json + 每步命令输出与文件修改快照
  memory/               MEMORY.md · observations.jsonl · working.jsonl · graph.json
                        forgetting.md · engines.json · dreams/（审计）
  uploads/              你发的图与生成的图
  metrics.jsonl         自报告（延迟、失败、明确反馈与完成）
```

磁盘预算自动执行（`config.json → storage`）：截图 200MB / 3 天、生成图 300MB / 60 天，超 80% 从最旧删，被最近对话引用的图永不删；每 6 小时与开机各维护一次；设置里有"全部忘掉"。

## 自我改进

Echo 不改自己的代码，只取这件事里保守的那一半：**冻结评估器**（`tests/selftest.mjs`，隔离沙箱，离线 69 条 + 实时 79 条断言，断言的是设计不变量而非实现细节）、公开的迭代日志（假设、分数、判决、教训，见 [docs/rsi-log.md](docs/rsi-log.md)），以及一条规矩：判据只增严，不放松。

<a id="未来规划"></a>
## 未来规划

Echo 还在 alpha。方向是：让这个私人 agent 真正能**动手**，并沿用它在记忆上的那套纪律——有预算、可解释、可回滚。

### Computer use（计划中）

地基已经在：状态栏 App 负责截屏与本地 OCR，循环本来就能调工具，每个动作都落在审计轨迹里。Computer use 要把它从"看懂"推进到"动手"（`computer_use` 工具：点击、输入、滚动、切换应用）。

上线时的约束（草案；必须显式开启，绝不默认）：

- **模型提议、App 执行**——真正的操作放在状态栏 App（Accessibility API + `CGEvent`）里，单独授权；模型拿不到输入设备的直接句柄。
- **破坏性操作逐次确认**；应用与动作类型允许清单；确认粒度"每次问 / 同应用只问一次 / 全自动"。
- **每个动作留审计**（做了什么、在哪、哪个应用、前后快照哈希），格式与 `forgetting.md` 一样可读可删。
- **急停 + 硬预算**（每分钟/每天动作数），沿用搜索那套熔断思路。
- **dry-run**：先把计划讲一遍，你看过再给写权限。
- 也可以**直接插 computer-use MCP 服务**——MCP 支持已有，确认、审计、预算三条同样施加于它暴露的任何工具。

### 也在考虑

可选的 **embedding 检索**（现在是词法 BM25 + 实体图，零依赖，做成"想开就开"的索引）· 实体图的**双时态**（让"以前成立"的关系能显式失效）· 端点支持 OpenAI 兼容 `/audio` 时的**语音进出**。

### 明确不做

多用户托管、记忆云端同步、遥测、任何需要账号的东西。一个人、一台机器、一堆你可以随手删掉的明文文件。

# Echo v0.1.0-alpha.7 — 任务进度与结果反馈

本版本为**本地候选版，尚未上传 GitHub Release**。公开下载仍是 [v0.1.0-alpha.6](https://github.com/Lazarus-coder/echo-assistant/releases/tag/v0.1.0-alpha.6)。

## 本次变化

- **任务过程可见**：对话与执行详情展示当前动作、实际步骤计数、失败原因及结果入口。展开详情时进度继续更新，查看输出时保留焦点。
- **终态如实保留**：完成、失败、停止、预算耗尽和连接中断分别显示；刷新后仍可回看执行结果，旧消息继续可读。停止保留已完成步骤和部分回复，不撤销已经发生的动作；停止请求失败后可重试。
- **失败处理修复**：无法解析的请求 URL 返回 400；存储清理只统计实际删除的文件，删除失败不会被误报为已释放空间。
- **产品入口与安装说明**：更新双语 README、新增双语发布页和安装指南，说明能力边界、模型连接检查、日志查看与问题反馈。
- **打包隔离**：试装只写临时目标目录，不启动现有服务或打开应用；清理继承的运行配置变量，自测的屏幕缓存清理不触及用户文件。

## 安装与升级

需要 **macOS 13 或更高版本**，并提前安装 **Node.js 22.13 或更高版本**。macOS 包附带项目运行依赖，**不附带 Node.js**。

安装文件为 `Echo-0.1.0-alpha.7-macos.dmg`、同名 ZIP 和 `SHA256SUMS-macos`。应用采用 **ad-hoc 签名，未经过 Apple 公证**；macOS 可能要求确认打开。

升级前备份安装目录中的 **`data/` 和 `config.json`**。`data/runs/` 保存独立的执行输出与文件快照，对话导出不包含这些内容。Alpha 阶段的界面与数据格式仍可能调整。

安装操作与模型设置见[安装指南](getting-started.md#中文)。其中的公开下载链接仍指向 alpha.6；本地候选包以本次交付文件为准。

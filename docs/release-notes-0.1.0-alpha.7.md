# Echo v0.1.0-alpha.7 — 任务反馈、健壮性与跟进闭环

本版本为**本地候选版，尚未上传 GitHub Release**。公开下载仍是 [v0.1.0-alpha.6](https://github.com/Lazarus-coder/echo-assistant/releases/tag/v0.1.0-alpha.6)。

## 本次变化

- **接口不再被畸形输入打断**：修复外部报告的 issue #1——其它 localhost 应用写入的畸形 cookie（如 `x=%`）会让解码抛错，导致**所有** `/api` 请求返回 500，连登录和退出都用不了。现在解码失败回退原始值，URL 路径里的畸形编码同样不再 500。
- **输入边界收口**：设置凭据时校验环境变量键名并拒绝带换行的值；屏幕屏蔽名单与陪伴场景只接受合法数组；屏幕截图只接受 png/jpeg/webp 的 data URL；记忆标签在读写两侧都归一化为字符串数组，损坏的条目只跳过当条；远程出图限定 http(s)、拒绝非图片内容、上限 20MB。
- **会话与运行记录**：修改口令后作废其它会话（当前会话保留）；登录失败计数定期清理；并发执行「全部忘掉」返回 409 而不是互相覆盖；回复落盘失败时仍然收尾运行记录，不再把运行永远停在"进行中"。
- **对话内跟进**：新增 `follow_up_create / list / update / complete` 四个工具。用户明确说"帮我盯着 / 持续跟进 / 到点提醒"时，Echo 直接在对话里把这件事接过去，沿用既有的准备预算、后台研究权限与主动交付链路；完成必须引用用户最近一条消息的原话，模型不能自行判定完成。顶栏新增「跟进 · N」入口。
- **一键接管线索**：主动消息锚定 Dream 待跟进线索时附带「加入跟进」按钮，标题、完成标准与截止日期已预填；用户点击后才创建目标，同一条线索不会重复创建。提案由固定模板生成，不额外调用模型。
- **回来简报**：离开 6 小时以上再打开页面，主对话顶部出现「你不在的这段时间」卡片：主动消息、今天/已过截止的目标、待查看草稿、失败待重试、可接管线索与新增事实。由 `lib/brief.mjs` 经 `GET /api/brief` 做纯确定性聚合，不调用模型、不改任何状态。
- **任务过程可见**：对话与执行详情展示当前动作、实际步骤计数、失败原因及结果入口。展开详情时进度继续更新，查看输出时保留焦点。
- **终态如实保留**：完成、失败、停止、预算耗尽和连接中断分别显示；刷新后仍可回看执行结果，旧消息继续可读。停止保留已完成步骤和部分回复，不撤销已经发生的动作；停止请求失败后可重试。
- **失败处理修复**：无法解析的请求 URL 返回 400；存储清理只统计实际删除的文件，删除失败不会被误报为已释放空间。
- **凭据不进进程参数**：`bin/echo passwd/remember/search` 改为经标准输入传 JSON，口令不再出现在进程列表里，含引号的输入不再被截断。
- **产品入口与安装说明**：更新双语 README、新增双语发布页和安装指南，说明能力边界、模型连接检查、日志查看与问题反馈。
- **打包隔离**：试装只写临时目标目录，不启动现有服务或打开应用；清理继承的运行配置变量，自测的屏幕缓存清理不触及用户文件。

## 安装与升级

需要 **macOS 13 或更高版本**，并提前安装 **Node.js 22.13 或更高版本**。macOS 包附带项目运行依赖，**不附带 Node.js**。

安装文件为 `Echo-0.1.0-alpha.7-macos.dmg`、同名 ZIP 和 `SHA256SUMS-macos`；源码包为 `echo-assistant-0.1.0-alpha.7.tar.gz` 与 `SHA256SUMS`。应用采用 **ad-hoc 签名，未经过 Apple 公证**；macOS 可能要求确认打开。

升级前备份安装目录中的 **`data/` 和 `config.json`**。`data/runs/` 保存独立的执行输出与文件快照，对话导出不包含这些内容。Alpha 阶段的界面与数据格式仍可能调整。

安装操作与模型设置见[安装指南](getting-started.md#中文)。其中的公开下载链接仍指向 alpha.6；本地候选包以本次交付文件为准。

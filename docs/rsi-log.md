## 收敛判定

- R3 → R4：离线分数不变（均 100%），实时 98.1% → 100%。按"连续两轮增益 < 评估噪声"判定收敛。
- 最终：**离线 51/51，实时 60/60（100%）**；在线搜索从 23–44s 优化到 **3–8s**（R7）。
- 冻结判据总数：**60 项**（A4 / B10 / C11 / D4 / E11 / G10 / F10）。
- R7 之后的残余提升空间不在可自动验证范围内（需要真实使用若干天，才能给主动服务的"被接住率"积累样本；参考 [landscape.md](landscape.md) 里的同类项目坐标系）。

## 当前判据明细

- **A 静态**：模块语法、服务健康、静态资源、bootstrap。
- **B 安全**：401/403、错误口令、13 例内网/公网判定、SSRF（含 metadata）、明文 key 扫描。
- **C 记忆与遗忘**：强度单调性（时间/重要度/使用）、去重、淡出、遗忘日志可解释、复活、明确遗忘、容量淘汰、检索召回。
- **D 上下文**：token 估算、预算裁剪、压力判定、摘要覆盖不丢中间段。
- **E 运行时**：预算淘汰、屏幕默认关、L0 写入、黑名单不送模型、存储计量、自报告、MCP 状态。
- **G 决策**：bandit 学习、探索偏向、门槛自适应、台账 EV 排序、反馈接口、结算闭环、回放模拟（bandit 比固定策略 +40%）、降级链。
- **F 实时**：抓取搜索时延、对话流、强制联网确实调工具、视觉理解、出图落盘、实体图、滚动摘要。

## 已知残余弱点

- 主动服务的"被接住率"需要真实使用数据才能评价，离线只有模拟；样本 < 2 次时 bandit 不做惩罚（有意为之，避免早熟）。
- 语音 ASR/TTS、视频不在本网关开放；README 已标注。
- 屏幕感知依赖系统"屏幕录制"授权，首次必须人工点一次。
## R9（社区化重构）· 从"我的工具"到"任何人都能装的工具"

| 假设 | 改动（单变量：把自用假设外移成配置） | 判据 |
|---|---|---|
| 代码里的"我的选择"（厂商网关、搜索引擎、记忆强度）是社区化的最大障碍，而不是功能缺口 | 新增 `lib/providers.mjs` 提供方目录（上游预设 / 搜索 8 种 / 记忆 4 档）；搜索改成可配的提供方链；BYOK 六步引导 + `GET /api/onboarding|providers|permissions`；默认端点与安装脚本不再预设厂商 | 新增 **H 轨 17 条**：目录完整性、"无厂商默认"不变量、引导写入（密钥→echo.env 600、config 不含密钥）、档位展开、`none` 时不下发联网工具、未配出图模型时无 `image_gen` |

离线从 52/52 → **69/69**。三处真缺陷在过程中被抓出并修掉：记忆档位补丁合并到错误层级（选档不生效）、密钥无法清除（空值被跳过）、`install.sh` 仍带厂商默认值。
教训：**"社区化"是可以被断言验证的**——把"不该出现的默认值"写成不变量，比人眼审查可靠。

## R10–R11（伴随模式与输入润色）· 真实使用路径暴露的问题

| 轮次 | 假设 | 改动 | 判据 |
|---|---|---|---|
| R10 | 润色要"猜得准"且"不编"，靠提示词不够 | CoT 三步（意图/缺口/假设/落笔）+ 只让有效重叠的记忆参与 + **确定性护栏**（记忆独有名词漏进正文就去记忆重写） | 新增 **I 轨 13 条**（含本地桩端点：上下文确实送达 / 泛化名词不引记忆 / 护栏触发 / 空与超长被拒） |
| R11 | 伴随模式的风险是"烦人"与"烧钱"，不是功能缺失 | 变化检测先挡帧、每小时候预算、最小间隔、连续忽略自动冷却、场景化口吻、气泡带 why；悬浮窗不抢焦点、可暂停 | 新增 **J 轨 11 条**（含回归：被节流帧不得污染基线） |

两个真缺陷是在**真实链路**里抓到的，而不是离线造出来的：① `pausedUntil` 用字符串与时间戳比较 → 暂停与退避完全失效；② 被节流跳过的帧被写成比较基线 → 长时间停在同一个聊天窗口会成为永久盲区。两条都已写成判据。

离线 95/95、实时 104/104；DMG 安装路径（挂载→临时 HOME 试装→装出的副本自测）随版本一起验证。

## R12（2026-10-20，未发布）· 从线索到查证、跟进与结束

这轮围绕「聊天里提到注册受阻，助手发现并核实相关截止日期」实现完整服务链，不把它当成一次单变量效果实验。现有记录继续作为产品开发日志；发布内容另见 `CHANGELOG.md` 的未发布条目。

| 需要解决的问题 | 实现 | 必须守住的判据 |
|---|---|---|
| 只存聊天不等于记住何时该帮忙 | 显式开启后扫描新用户消息，记录具体事务身份、原始消息和未决问题；发现项七天未采纳即停止 | 不扫描开启前消息；不从情绪建任务；不伪造来源、不重复建同一事务 |
| 提醒前没有完成实际查证 | 复用 harness，加入限定的搜索/读取工具循环，支持公开网页、PDF、共享文档、选定文件夹 | 只读白名单、范围与权限实时重查、取消传播、次数/时间/输出限制 |
| 引用正确不等于日期适用 | 核对原文、完整日期、学校/项目/周期/类别/阶段、已确认官网；保留冲突与未知 | 不把申请/缴费/注册日期混用，不把搜索摘要当证据，不补造时区 |
| 一次失败会永久吃掉截止提醒 | 持久重试、成功后消费里程碑、日期与来源合并观察、相关内容指纹、启动/唤醒补查 | 失败与无变化分开；相同事实不重复提醒；旧证据不能在唤醒后抢先投递 |
| 事务完成后仍提醒 | 对真实用户消息做保守的完成识别，附消息依据结项；保留手动完成与纠正入口 | 否定、条件、未来计划、转述、部分成功不直接结项 |
| 新功能增加干扰和不透明成本 | 研究与呈现分别开关；沿用静默、专注、预算；界面显示来源/疑问/检查/重试；诊断记录研究次数、工具调用与 token | 不从点击或沉默推断有用，不宣称尚未测量的漏报率或节省时间 |

实现范围为本地 Mac、Echo 新对话、主动分享的网页/PDF/文档与选定工作区文件夹；邮箱、日历与全浏览器采集尚未接入。PDF 采用当前 `pdfjs-dist 6.4.299`，最低 Node 更新至 22.13，未自行重写解析器。关系层保留自然克制的偏好与手动人物背景，不增加独立情绪提醒。

验证采用临时 `ECHO_DATA_DIR`、独立配置和模拟模型/来源；不读取真实凭据、不改用户配置、不重启已安装服务。新增回归覆盖需求发现、日期适用性、重试、研究工具与文件权限、PDF、API 隐私重置以及界面草稿/错误恢复。真实上游表现、真实注册网站与长期误报/漏报仍属于后续使用评估。

# macOS 权限与后台运行

Echo 使用你配置的模型接口处理对话。屏幕感知、工作区工具、后台研究和局域网访问都有独立开关。[入门指南](getting-started.md) · [英文版](../permissions.md)

## 模型接口与密钥

Echo 使用你自己的密钥（BYOK），支持兼容 OpenAI 的接口。以下三种方式均可配置模型。

1. 首次打开网页时，按引导选择端点、输入密钥、选择模型，再配置记忆、搜索和权限。端点不支持列出模型时，可以手动填写模型 ID。
2. 从源码运行 `./install.sh`，按提示输入端点和密钥。安装器也可以从登录终端读取 `OPENAI_BASE_URL` 和 `OPENAI_API_KEY`。
3. 在 `data/echo.env` 写入这两个变量，或在启动服务的进程环境中设置。文件权限为 `600`，密钥不写入 `config.json`，也不提交到 Git。

如果某个端点指定了自定义密钥变量，它只使用该变量。后台任务使用配置的辅助模型，或回退到所选默认模型。

| 功能 | 接口要求 |
|---|---|
| 文本、推理、流式输出、工具调用 | 支持所需功能的 `/chat/completions` 接口 |
| 图片输入 | 支持视觉输入的模型 ID |
| 图片生成 | 可生成图片的模型 ID；留空即停用该工具 |
| 托管搜索 | `gateway` 提供方需支持带 `web_search` 的 Responses API，例如阿里云百炼 |

## 屏幕录制权限

默认关闭屏幕感知。轻量和标准记忆档位保持关闭，深度档位会开启。启用后，菜单栏应用 EchoBar 定时截屏，在本机通过 Apple Vision 识别文字。默认识字模式只向模型发送文字；如果你显式选择图像模式，屏幕感知可以把截图发给视觉模型。

临时截图使用当前资料目录的私有暂存区，处理后删除。维护任务可清理异常中断后遗留的暂存文件。锁屏、键鼠长时间空闲时跳过采集。在 **设置 → 屏幕感知** 中可按应用、窗口标题和识别文字设置排除项，默认列表为空。

1. 点击菜单栏的 Echo 图标，再选授予屏幕录制权限的选项。
2. 在 **系统设置 → 隐私与安全性 → 屏幕录制** 中允许 EchoBar。系统版本不同，面板名称可能略有差别。
3. 如果系统要求重启，运行 `./bin/echo down && ./bin/echo up` 重新启动菜单栏应用和服务。
4. 在 **设置 → 引导与权限 → 测试屏幕录制权限** 中检查结果。

未授权时，Echo 跳过采集，继续提供对话等功能。只有主动点击授权或权限测试时才请求系统许可。

### 伴随模式

在菜单栏或 **设置 → 伴随模式** 中开启。它共用屏幕录制权限，默认每 20 秒检查一次，普通屏幕感知则默认每 5 分钟检查一次。伴随模式只处理本地识别出的文字，遵守排除项和变化检查，屏幕没有变化时跳过模型调用。可以随时暂停，连续三次收起气泡后默认会暂时静默。

旧版 alpha.6 的安装包曾有排除项问题，可能把已排除窗口的识别文字发给模型。如果仍使用该版本并依赖排除项，请先关闭伴随模式。alpha.10 对两条采集路径都检查应用、标题与识别文字。

### 更新和重新授权

macOS 按应用身份管理屏幕录制权限。打包和安装脚本尝试使用本机临时签名。当前版本没有开发者 ID 签名或公证，移动、更新或重新编译后可能需要再次授权。磁盘映像安装器把菜单栏应用放在 `~/Library/Application Support/Echo/Echo.app`，固定标识为 `com.echoassistant.menubar`。源码安装器发现已有该应用时会复用它。

## 通知与主动打扰

系统通知通过 `osascript` 发送。未看到横幅时，可在 **系统设置 → 通知** 中检查发送应用的通知权限，菜单栏红点仍可提示未读。

时机偏好按这台 Mac 上的 Echo 资料目录学习。同一安装中的多位聊天者共享这套偏好。启用主动消息或伴随气泡后，Echo 按本地时间把一天分为若干三小时时段，每个时段每天最多记录一次“聊过天”。这项记录不含聊天文字，学习使用当前时区最近 14 个本地日期。“全部忘掉”会清除此记录。

下表为预设的初始参数。间隔为零时，原有最短间隔仍然生效。近期时机反馈以及跨日期的聊天规律会调整实际值。

| 预设 | 可选建议的额外间隔 | 最长等待常聊时段 | 内容分数门槛 |
|---|---|---|---|
| 安静 | 120 分钟 | 6 小时 | 0.70 |
| 均衡 | 0 分钟 | 3 小时 | 0.62 |
| 积极 | 0 分钟 | 0 小时 | 0.52 |

在 **主动服务 → 打扰时机与反馈学习** 中可以对照初始值和今天的实际值。明确要求准备的事项优先；静默时段、对话进行中、正在开会或专注、暂停和次数上限都继续生效。

点 **有用** 或 **没用** 评价内容，会影响同类主题和帮助方式的排序。点 **来得正好** 或 **时机不合适** 评价投递时段，会影响今后同类提醒的时机。“时机不合适”还会暂停打扰 30 分钟。可回到原消息修改反馈。

本机算法选择内容及其依据，模型根据已选依据和允许后台使用的交流偏好组织措辞。伴随气泡使用一段选定的识别文字，主动消息可在屏幕感知开启时使用近期活动摘要。已保存的准备结果可直接送达。没有合适候选时不调用模型，优先级以 0 到 1 的分数表示。

打开 **主动服务 → 预览候选提醒** 可查看最多三个候选。预览和投递共用排序与时机检查，预览不调用模型、不消耗通知额度，也不记录投票。聊天主题按规范化标题静音，因此来源 ID 变化也适用；伴随提示按线索类型静音，例如测试失败。在预览或原消息中可以撤销静音，来源已失效时可按保存条目和日期撤销。用户要求的准备结果沿用原有投递规则。

## 登录启动与访问地址

`./install.sh` 注册两个用户级 launchd 任务。服务 `com.echo.chat` 运行 `server.mjs`，登录时启动，异常退出后重启，日志在 `data/logs/`。菜单栏任务 `com.echo.menubar` 只在图形登录会话中运行；从源码构建它需要 `swiftc`。

```bash
./bin/echo status       # 查看进程、监听地址、记忆和主动服务状态
./bin/echo logs         # 跟踪日志
./bin/echo down         # 停止服务和菜单栏图标
./bin/echo up           # 启动服务和菜单栏图标
xcode-select --install  # 需要从源码编译且尚未安装工具时使用
```

**设置 → 引导与权限** 或 `GET /api/permissions` 可查看端点配置、后台任务、编译器、监听地址和资料目录。

从 alpha.8 起，新资料默认只监听 `127.0.0.1:8787`。若从 alpha.6 升级，请核对网络设置，该版默认监听所有网络接口且没有口令。若需手机访问，先用 `./bin/echo passwd` 设置口令，再用 `./bin/echo auth on` 启用验证，在 `config.json` 中设置 `"bind": "all"` 并重启。显式设置的 `ECHO_BIND` 优先。会话 Cookie 使用 HttpOnly 和 SameSite=Strict，写入请求还需专用请求头。

## 本地文件与删除

默认资料目录 `data/` 保存密钥、对话、上传文件、日志、指标及记忆文件，例如 `MEMORY.md`、`observations.jsonl`、`working.jsonl`、`graph.json` 和 `forgetting.md`。可以自行查看和备份。截图和图片按 `config.json` 中的 `storage` 限额清理。**设置 → 隐私兜底** 可用来清除资料；默认保留对话，也可选择一并清除。

**记忆 → 相处方式** 将交流偏好和手动填写的人物背景存入 `data/state.json`。启用个性化和记忆注入后，交流偏好和最多三份与当前对话匹配的人物背景可发给所选模型。简短追问可以借助上一条用户消息识别所指人物。后台主动消息和伴随模式只接收交流偏好。保存偏好本身不创建通知或额外模型调用。

关闭相关开关或删除人物资料后，后续请求停止带入这些内容。已经发给提供方的请求和已有对话不受影响。交流偏好、人物背景包含在 JSON 备份中，“全部忘掉”可清除。系统不单独保存情绪评分或情绪档案。克制措辞、标明来源属于模型指令，回复可能出现偏差。

## 工作区与 MCP

默认停用工作区工具。仅可在运行服务的 Mac 上打开 **工作区**，选择已存在的目录，分别允许读取、编辑、运行 Shell。文件工具限制在选定目录内，拒绝符号链接和 Echo 私有资料，替换前检查文件内容哈希。允许编辑后，助手可以直接修改文件，系统保存修改前后的快照供核对。

在当前对话选择 **只读规划**，将交互工具限定为查找、阅读源码及查看已有结果。选择 **执行任务** 后恢复工作区已允许的功能，既有对话默认使用此模式。切换模式后，保存对话和后台记忆仍沿用资料设置。

每一次 Shell 和 MCP 工具调用都要求核对并批准具体输入，批准请求五分钟后过期，拒绝会结束该轮任务。Shell 使用本机账号权限，工作目录不能限制它的文件或网络访问。配置标准输入输出型 MCP 服务会启动所配置的程序，只添加可信服务。官方 MCP SDK 处理协商、传输和取消；子进程所需凭据必须在该服务的 `env` 中显式设置，模型密钥不自动传递。

点击停止会终止本地 Shell 进程组并要求 MCP 取消。已经发生的修改需要另行恢复，远程服务可能继续执行。重启不会重放中断的操作，关闭能力会取消相应运行。外部手机或局域网对话无法使用工作区和 MCP，配置、审批与下载输出只允许本机回环访问。

运行记录、命令输出和编辑快照保存在 `data/runs/`，可能包含项目资料。“全部忘掉”会清除这些记录。对话 JSON 导出不含运行目录，请单独备份。用于模型推理的文件内容和工具结果会发送到所选模型接口。后台目标准备仅可读取，不会获得无人值守命令执行权限。

## 后台研究

默认关闭。在本机的 **主动服务** 中启用。“从新对话发现”是独立开关，只分析启用后写入的新消息，不会改变普通记忆开关。相关消息和事项可能发给已配置的模型，公开搜索词可能发给搜索服务。系统不据此建立情绪或关系档案。

每项目标可以指定公开网址、最多五份主动上传的 PDF 或文本，以及启用工作区内最多三个相对目录。读取目录沿用工作区路径、符号链接和私有资料限制。后台工具无权执行 Shell、调用 MCP、编辑文件、提交表单或向他人发消息。文档在本地提取，选中片段在使用时发给模型。上传文档存于 `data/research/documents/`，包括在 JSON 备份中，“全部忘掉”会删除它们。研究产物放在 `data/runs/`。

你确认的官方域名决定哪些来源可支持已核实的截止日期。搜索结果本身不能取得官方资格，未知或冲突的日期会保留为候选。研究和通知分别授权，静默时段和提醒额度仍然生效。关闭研究会取消进行中的工作；仅清除记忆也会推进发现起始时间，避免旧对话被立刻重新导入。定时检查需要 Mac 醒着且 Echo 正在运行。
